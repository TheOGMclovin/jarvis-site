Privacy policy

Last updated: October 8, 2026

Jarvis is a personal application used by one person, its owner, on their own computer.

What it accesses

With the owner's permission, Jarvis reads the owner's Google Calendar, Google Tasks and Gmail, and can update the owner's own calendar events and tasks (for example, adding reminders).

Where data goes

Data retrieved from Google is stored only on the owner's computer. It is not sold, shared with third parties, used for advertising, or transferred anywhere else. Jarvis has no server and no other users.

Google API data

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Jarvis's access at any time at myaccount.google.com/permissions, which stops all further access.

Questions: open an issue at github.com/TheOGMclovin.
